# Voice2Sub — Ứng dụng tạo phụ đề AI local cho Windows, macOS và Linux

**Voice2Sub** là ứng dụng desktop giúp tạo phụ đề AI, transcript và file phụ đề có thể chỉnh sửa từ video/audio local.

Ứng dụng phù hợp cho creator, editor, giáo viên, học sinh/sinh viên, podcaster, người làm nội dung và những ai cần xử lý phụ đề riêng tư trên máy tính mà không muốn bắt đầu bằng việc upload video/audio lên website.

## Tính năng chính

- Tạo phụ đề từ video và audio local.
- Nhận diện giọng nói và chuyển thành văn bản.
- Chỉnh sửa nội dung phụ đề và thời gian hiển thị.
- Xuất SRT, VTT, TXT, LRC, CSV và JSON.
- Xử lý nhiều file với batch workflow.
- Hỗ trợ nhiều ngôn ngữ nhận diện.
- Có tuỳ chọn xuất phụ đề tiếng Anh khi cần.
- Hỗ trợ Windows, macOS và Linux.
- Hỗ trợ Windows x64 MSI installer và Microsoft Store.
- Hỗ trợ macOS Universal DMG cho Apple Silicon và Intel.
- Hỗ trợ Linux `.deb` và portable `.tar.gz`.
- Hỗ trợ CUDA trên hệ thống NVIDIA tương thích.
- Hỗ trợ workflow tối ưu cho Apple Silicon/Metal.
